# 👋 codecloud-dev

维护 **MoX 系列**开源项目：Android 上的液态玻璃 Linux 终端、rootless 容器引擎、WebGPU 计算框架与自主运维 Agent SDK。

## 🚀 核心自研仓库

| 仓库 | 说明 |
| --- | --- |
| [moxsh-terminal](https://github.com/codecloud-dev/moxsh-terminal) | Android 液态玻璃 Linux 终端：Rust 内核、PRoot 容器、插件商店与 AI 助手，完全 Termux 兼容 |
| [moxsh-proot](https://github.com/codecloud-dev/moxsh-proot) | PRoot 容器引擎：Rust ptrace 内核 + Go 安装器 + Python 运行时 + Lua 钩子 + C JNI 桥 |
| [moxwebgpu](https://github.com/codecloud-dev/moxwebgpu) | 零依赖 WebGPU 计算（GPGPU）框架：类型化张量、原生 WGSL 内核与惰性计算图 |
| [agent-core](https://github.com/codecloud-dev/agent-core) | 元认知协议引擎 + 分级自主护栏，平台无关的自主运维 Agent 核心 |
| [mox-id](https://github.com/codecloud-dev/mox-id) | MoX 家族轻量身份后端：GitHub OAuth 登录、账号、设备与会话 |
| [moxsh-suite](https://github.com/codecloud-dev/moxsh-suite) | 全家桶 monorepo：设计原型、文档、插件规范、App 与官网子模块 |
| [moxsh-plugins](https://github.com/codecloud-dev/moxsh-plugins) | moxsh-terminal 插件目录：官方与社区插件 |
| [mox-site](https://github.com/codecloud-dev/mox-site) | 官网（构建产物：https://mox-site.pages.dev ） |
| [molecule-os](https://github.com/codecloud-dev/molecule-os) | MoleculeOS —— 面向 AI 公司的 AI Native 操作系统 |
| [molecule-lm](https://github.com/codecloud-dev/molecule-lm) | 0.1B 级开源语言模型：融合 RoPE-NTK/GQA/SwiGLU 等架构，纯 CPU 训练 CI |
| [pdf-lib-plus](https://github.com/codecloud-dev/pdf-lib-plus) | pdf-lib 社区维护分支：相同公开 API 与 MIT 许可，已修复上游安全问题 |

> 另有若干 `awesome-*` 仓库为技术清单类 fork，仅作收藏与索引，不参与主产品线。
