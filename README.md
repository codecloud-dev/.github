# codecloud-dev · 默认社区文件

这个仓库提供该账号下**所有仓库的默认社区健康文件**：仓库内若没有同名文件，GitHub 会自动使用这里的一份。

| 文件 | 作用 | 是否支持跨仓默认 |
| --- | --- | --- |
| `CONTRIBUTING.md` | 怎么参与贡献 | ✅ |
| `CODE_OF_CONDUCT.md` | 社区行为底线 | ✅ |
| `SECURITY.md` | 漏洞往哪报 | ✅ |
| `ISSUE_TEMPLATE/` | 反馈结构化 | ✅ |
| `PULL_REQUEST_TEMPLATE.md` | PR 结构化 | ✅ |
| `CHANGELOG.md` | 版本变更索引 | ❌（仅作说明，各仓自维护） |
| `CODEOWNERS` | 审核责任 | ❌（仅仓内生效，此处是模板） |

各仓已有的同名文件**优先于**这里的默认值，不会被覆盖。具体内容请直接看对应文件；各仓特有信息（构建命令、协议、安全边界）以该仓内文件为准。

> 仓库级改动请提到对应仓库，不要提在这里。
